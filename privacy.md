# Privacy Policy

This policy covers the n8n app, a personal workflow automation run by its owner on a private n8n instance.

## Who uses this app

The app is used only by its owner and by people the owner has personally invited. It is not offered to the public.

## Data accessed

With the consent of the account holder, the app uses Google OAuth to access the Gmail data of the authorized account, which can include message content, headers, labels and attachments, as needed to run the automated workflows the owner has configured.

## How data is used

Gmail data is used only to run those workflows, such as reading, labeling, organizing and sending email on behalf of the account holder. It is not used for advertising and is not used to train AI or machine learning models.

## Sharing

Data is not sold. It is not shared with third parties except the services the owner has deliberately connected to a workflow, or where required by law.

## Storage and retention

OAuth tokens and workflow data are stored in the n8n instance controlled by the owner. Data is kept only as long as the workflows need it.

## Revoking access

Access can be removed at any time from the Google Account permissions page at https://myaccount.google.com/permissions.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Contact

Questions can be raised by opening an issue at https://github.com/patrickduffyjr/n8n-k7q3x/issues.
